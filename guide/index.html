PT 루틴 시작 가이드

설치 없이 폰 브라우저로 쓰는 운동·식단 기록 앱이에요. 홈 화면에 추가하면 진짜 앱처럼 쓸 수 있어요. 5분이면 끝나요.

앱 열기 · trainerdata.github.io/pt-routine/
카카오톡에서 링크를 눌렀다면, 화면 오른쪽 아래 나침반(또는 ⋯) 버튼 → "Safari로 열기"를 눌러 Safari에서 열어주세요. 홈 화면 추가는 Safari에서만 돼요.
1단계 · 홈 화면에 앱 추가

1Safari 아래쪽 공유 버튼

네모에 위쪽 화살표 모양 버튼이에요. 안 보이면 화면을 살짝 위로 올리거나, 주소창 옆 ⋯ 버튼 안에 있어요.

2"홈 화면에 추가"

목록에 안 보이면 목록을 위로 밀어 올려보세요.

3오른쪽 위 "추가"

이름은 "PT 루틴" 그대로 두면 돼요.

4홈 화면의 PT 루틴 아이콘으로 열기

이제부터는 항상 이 아이콘으로 열어요. Safari와 아이콘은 기록이 따로 저장돼서, 처음 가입도 아이콘으로 열어서 하는 게 좋아요.

2단계 · 가입하고 운동하기

5이름과 PIN 정하기

PIN은 숫자 4~8자리예요. 폰을 바꿀 때 기록을 불러오는 데 필요하니 꼭 기억해 두세요. 이름이 다른 팀원과 겹치면 성까지 넣어주세요.

6내 캐릭터 미리보기

슬라이더를 밀면 LV 30까지 어떻게 변하는지 볼 수 있어요. 운동할수록 캐릭터 몸이 좋아져요.

7체형·머리·색 고르기

지금의 나와 비슷한 체형을 고르고, 머리 모양·피부·색을 골라요.

81RM 칸 누르기

1RM은 1번 겨우 들 수 있는 최대 무게예요. 칸을 누르면 다이얼이 나와요.

9다이얼 굴리고 완료

위아래로 굴려서 고르고 "완료". 모르면 5번 겨우 드는 무게 × 1.15 정도로, 그것도 모르면 "모름"으로 둬도 돼요.

10이 캐릭터로 시작하기

하루 목표 칼로리·단백질은 그대로 둬도 돼요. 맨 아래 버튼을 누르면 가입 끝!

11운동 시작

홈 화면에 오늘 할 부위가 나와요. "운동 시작"을 눌러요. 다른 부위를 하고 싶으면 아래 "다른 부위".

12세트마다 숫자 터치

한 세트 끝날 때마다 숫자를 누르면 휴식 타이머가 자동으로 돌아요. 무게·횟수는 무게 칸을 눌러 바꿔요. 위쪽 "● 저장됨"은 트레이너에게 기록이 전달됐다는 뜻이에요.

13운동 완료

맨 아래 "운동 완료"를 누르면 끝. "오늘 기록이 팀 시트에 저장됐어요"가 뜨면 트레이너가 볼 수 있어요.

14식단도 터치 한 번

식단 탭에서 아침·점심·간식·저녁에 먹은 걸 누르면 칼로리와 단백질이 자동으로 계산돼요.

15폰을 바꿨을 때

새 폰에서 앱을 열고 첫 화면 맨 아래 "이미 쓰던 기록이 있어요"에 이름과 PIN을 넣으면 레벨·캐릭터·기록이 그대로 돌아와요.

카카오톡에서 링크를 눌렀다면, 오른쪽 위 ⋮ → "다른 브라우저로 열기"를 눌러 삼성 인터넷이나 크롬에서 열어주세요. 쓰는 브라우저에 맞춰 A 또는 B를 따라 하세요.
1단계 · 홈 화면에 앱 추가

1A. 삼성 인터넷: 아래쪽 메뉴(≡)

화면 맨 아래 오른쪽 줄 세 개 버튼이에요.

2A. "현재 페이지 추가"

메뉴에서 "현재 페이지 추가"를 눌러요.

3A. "홈 화면"

4A. "추가"

5B. 크롬: 오른쪽 위 점 세 개(⋮)

6B. "홈 화면에 추가"

"앱 설치"라고 나오면 그걸 눌러도 같아요.

7B. "추가" 또는 "설치"

8홈 화면의 PT 루틴 아이콘으로 열기
