# PT 루틴

팀이 같이 쓰는 웨이트 루틴 + 식단 기록 웹앱이에요. 설치 없이 폰 브라우저로 열어서 쓰면 돼요.

- 4분할 순환: 가슴 → 등 → 어깨 → 하체 (요일 고정 아님. 순서대로 돌아가요)
- 사이클 교체: 한 바퀴 끝날 때마다 부위별 보조 종목 2개만 비슷한 종목으로 바뀌어요 (메인 운동은 고정, 항상 기본 루틴 기준이라 크게 안 벗어나요)
- 무게 자동 추천: 모든 세트를 목표 횟수 상단까지 채우면 다음엔 무게 올리기, 2번 연속 못 채우면 10% 낮추기
- **1RM만 입력하면** 종목별 시작 무게와 워밍업 세트 무게가 자동으로 계산돼요
- 세트 체크하면 휴식 타이머, 무게/횟수 다이얼, 지난번 기록 불러오기
- 식단 선택 → 칼로리·단백질 합계, 체중·걸음 수·수면 기록
- XP·레벨·캐릭터, 주간 리포트 그래프
- 하루 기록을 텍스트로 복사해서 트레이너나 Claude에게 보내면 피드백 받기

## 팀원용: 시작하기

1. 링크 열기: **https://trainerdata.github.io/pt-routine/**
2. 처음 화면에서 이름, 1RM 4개(벤치·데드·스쿼트·OHP), 하루 목표 칼로리·단백질 입력 → **시작하기**
   - 1RM을 모르면 5회 겨우 드는 무게 × 1.15 정도로 넣으세요
3. 홈 화면에 추가하면 앱처럼 쓸 수 있어요
   - 아이폰: Safari 공유 버튼 → 홈 화면에 추가
   - 안드로이드: Chrome 메뉴 → 홈 화면에 추가

### 내 기록은 어디에 저장되나요?

세트를 체크하거나 식단을 입력하면 **폰에 바로 저장**되고, 1~2초 뒤 **팀 구글 시트에도 자동 저장**돼요.
인터넷이 끊겨 있으면 폰에 모아뒀다가 연결되면 알아서 올려요. 화면 위쪽에 `● 시트 저장됨`이 보이면 올라간 거예요.

- 처음 시작할 때 **이름 + 숫자 PIN(4~8자리)**을 정해요. 이름이 다른 팀원과 겹치면 성까지 넣어주세요
- 폰을 바꾸거나 PC에서 열 때: 처음 화면의 **이미 쓰던 기록이 있어요**에 이름과 PIN을 넣으면 기록이 그대로 돌아와요
- 이미 폰에 기록이 쌓여 있던 사람은 **내 정보**에서 PIN을 정하는 순간 지난 기록까지 전부 시트로 올라가요
- 다른 팀원은 내 기록을 볼 수 없어요. 시트는 관리자(트레이너)만 봐요

## 관리자용: 구글 시트 자동 저장 켜기 (처음 한 번, 5분)

1. https://sheets.new 로 새 구글 시트를 만들고 이름을 `PT 루틴 기록`으로 바꿔요
2. 메뉴 **확장 프로그램 → Apps Script**를 눌러요
3. 열린 편집기의 내용을 전부 지우고 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 그대로 붙여넣은 뒤 저장(💾)해요
4. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 계정: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포** → 권한 승인 창이 뜨면 내 구글 계정 선택 → "Google에서 확인하지 않은 앱" 화면에서 **고급 → (안전하지 않음)으로 이동 → 허용**
   (내가 방금 만든 스크립트라서 뜨는 경고예요)
6. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사해요
7. [`routine.js`](routine.js)의 `const SYNC_URL = '';` 따옴표 안에 붙여넣고 Commit

시트에는 탭 3개가 자동으로 생겨요.

| 탭 | 내용 |
| --- | --- |
| 기록 | 회원·날짜별 한 줄: 운동, 완료 세트, 종목별 무게×횟수, 칼로리, 단백질, 체중, 걸음 수, 수면, 컨디션, 통증, 식단 |
| 회원 | 이름, 1RM 4개, 현재 사이클, 마지막 저장 시각 |
| 원본 | 기록 복원용 데이터 (손대지 마세요) |

주간 점검은 **기록** 탭을 필터하거나, 그대로 복사해서 Claude에게 붙여넣고 분석을 맡기면 돼요.

> 회원이 PIN을 잊어버리면 **회원** 탭에서 그 사람 줄을 지워주세요. 같은 이름으로 새 PIN을 정하면 다시 이어서 저장돼요 (지난 기록도 그대로 남아 있어요).
> Code.gs를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영돼요. URL은 그대로예요.

## 관리자용: 루틴 바꾸기

종목, 세트, 무게 비율, 식단, 자세 가이드는 전부 [`routine.js`](routine.js) 한 파일에 있어요.
GitHub에서 파일을 열고 연필 아이콘(Edit)으로 고친 다음 **Commit changes**를 누르면 1~2분 뒤 팀원 모두에게 반영돼요.

| 바꾸고 싶은 것 | `routine.js`에서 고칠 곳 |
| --- | --- |
| 종목·세트·횟수·휴식 | `DAYS` 안의 `{n:'종목명', s:세트, r:'횟수', rest:'휴식'}` |
| 시작 무게 | `w:['bench', .75]` → 벤치 1RM × 75%. `'db'`를 붙이면 한 손 덤벨 무게 (2kg 단위) |
| 무게 없는 종목 | `kg:'맨몸'` |
| 사이클마다 바꿔 끼울 후보 | 각 종목의 `v:[{n:'...', w:[...]}, ...]` (`v`가 없으면 절대 안 바뀜) |
| 사이클마다 바꾸는 개수 | `SWAPS_PER_CYCLE` (기본 2) |
| 기본 칼로리·단백질 목표, 주간 운동 목표 | `DEFAULT_TARGETS`, `WEEK_GOAL` |
| 구글 시트 저장 주소 | `SYNC_URL` |
| 식단 선택지 | `MEALS` (`'약 800kcal · 단백질 40g'` 형식을 지켜야 합계가 계산돼요) |
| 준비운동 | `WU` |
| 자세 가이드 | `GN_RAW` (종목 이름이 같아야 연결돼요) |

기준 1RM 이름: `bench` 벤치프레스 · `dead` 데드리프트 · `squat` 스쿼트 · `ohp` 오버헤드프레스

> "지난번 무게"와 무게 추천은 **종목 이름**으로 기록을 찾아요. 종목 이름을 바꾸면 새 종목으로 취급돼서 기록이 이어지지 않아요.

## 파일 구성

```
index.html   화면 뼈대
style.css    디자인
routine.js   팀 공통 루틴·식단 데이터 (여기만 고치면 돼요)
app.js       앱 동작
apps-script/Code.gs  구글 시트 저장소 (Apps Script에 붙여넣는 코드)
```

빌드 과정이 없어서 파일을 고치면 바로 반영돼요. 로컬에서 확인하려면:

```bash
python3 -m http.server 8000
```

그다음 http://localhost:8000 을 열면 돼요.
